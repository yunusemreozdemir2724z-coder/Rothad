# Rothad Hanesi — Sargoth Baronluğu

GitHub Pages için hazır statik site.

## Yükleme yapısı

`index.html` ve `assets/` klasörü aynı seviyede olmalıdır:

```text
index.html
.nojekyll
README.md
assets/
  bremond.jpg
  esdicnha.jpg
  etirburg.jpg
  kalioc.jpg
  lenox.jpg
  murolas.jpg
  rothad-sancak.jpg
  sargoth-haritasi.jpg
```

## GitHub Pages

Settings → Pages → Build and deployment → Source: Deploy from a branch → aktif branch → `/(root)`.

ZIP dosyasını repository'ye tek parça olarak yüklemeyin. ZIP'i çıkarıp içindeki dosya ve `assets` klasörünü repository'nin köküne yükleyin.
